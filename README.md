# EduTrack SL – Student Academic Record Portal

## Overview
EduTrack SL is a simple GUI-based Python application that helps schools in Sierra Leone manage student academic records. It allows users to enter student details, calculate total scores, assign grades, and display remarks using structured programming principles.

This project is developed for **PROG103 – Principles of Structured Programming** at **Limkokwing University of Creative Technology, Sierra Leone**.

## Features
- GUI built with `tkinter`
- Input:
  - Student Name
  - Student ID
  - Course
  - Test Score (0–50)
  - Exam Score (0–50)
- Processing:
  - Total score calculation
  - Grade assignment using decision structures
  - Remarks generation
- Output:
  - Total score
  - Grade
  - Remark
  - List of student records
- Structured programming:
  - User-defined functions
  - Decision structures (`if`, `elif`, `else`)
  - Basic validation

## SDG Alignment
EduTrack SL supports **SDG 4 – Quality Education** by:
- Improving accuracy and transparency in grading
- Reducing manual paperwork
- Encouraging digital tools in schools

## Requirements
- Python 3.x
- Standard library only (uses `tkinter` and `tkinter.messagebox`)
